# Security boundary

This is an in-process memory library, not an authentication service or a tool-execution sandbox. Principals, capture metadata and integration callbacks must come from trusted host code. Retrieved text remains data, including when it appears in a JSON envelope or a summary.

Protect database and index files, backups and historical revisions. Storage is plaintext and history is retained. Retirement is not erasure; regex redaction is not comprehensive secret detection or anonymization. Revalidate external permissions before delivery when concurrent revocation matters.

If reporting a suspected boundary bug, use synthetic reproduction data and do not attach real memories or credentials. If the report itself contains a secret, do not open a public issue. The repository does not currently offer a dedicated private security intake channel.
